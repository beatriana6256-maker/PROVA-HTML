# Receitas simples para o cotidiano

Projeto de um site de receitas feito em HTML. A ideia é compartilhar pratos para preparar em família e mostrar como cozinhar pode reunir as pessoas.

## Páginas do projeto

- **Início (`inicio.html`):** apresenta o site, um texto sobre cozinhar em família e um vídeo do YouTube.
- **Receitas (`Receitas.html`):** traz as receitas de lasanha de frango e macarrão ao molho três queijos, com ingredientes e modo de preparo.
- **Envie sua receita (`forms.html`):** contém um formulário para preencher os dados de uma receita, além de um vídeo e uma tabela de exemplo.

## Como visualizar

Abra o arquivo `inicio.html` em um navegador e use os links do menu para acessar as outras páginas. Não é necessário instalar nada.

## Observação

O formulário é demonstrativo. As receitas enviadas não são salvas nem publicadas automaticamente.

## Tecnologias utilizadas

- HTML
- Imagens, áudio e vídeo
